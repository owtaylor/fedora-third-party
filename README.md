# fedora-third-party

The `fedora-third-party` tool is used to manage third-party repositories on Fedora.
It reads configuration files that say whichDNF repositories and Flatpak remotes,
to manage, and then, when the user enables (`fedora-third-party enable`) or disables
(`fedora-third-party disable`) third-party repositories, it enables and disables
the repositories as appropriate.

## Usage
See [fedora-third-party(1)](https://pagure.io/fedora-third-party/blob/main/f/doc/fedora-third-party.1.md)
